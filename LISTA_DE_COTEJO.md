# Lista de cotejo - Wiki colaborativa

## Criterios de evaluación

| Criterios a evaluar | Cumple (10 Puntos) | Sí | NO | Comentarios |
|---|---|---|---|---|
| **Estructura (sin puntaje pero se considera para la evaluación)** | Incluye los elementos siguientes: • Wiki colaborativa • Bibliografía en formato APA | | | |
| **Formato** (.25) | Incluye los siguientes elementos: • Letra de fuente y tamaño legibles • Imágenes y colores legibles • Referencias de contenidos citado en formato APA las fuentes y autores consultados. | | | |
| **Elementos de la wiki** (3.25) | Cumple con los elementos siguientes: • Tiene una presentación atractiva. • Se pueden localizar todos los elementos importantes. • Los enlaces para navegar están debidamente etiquetados, permitiendo al usuario navegar con facilidad • La información es sintética y clara. • Los datos son sólidos y de fuentes fiables. • El cuerpo del trabajo incluye citas, ya sean textuales o de paráfrasis, así como el listado de las referencias empleadas para su desarrollo. | | | |
| **Contenido** (4) | Cumple con los elementos siguientes: • Técnicas de recolección de información • Validez • Muestra • Tipos de muestreo • Confidencialidad • Piloteo | | | |
| **Comprensión** (1.5) | Cumple con los elementos siguientes: • Refleja la comprensión del tema • Elimina contenido innecesario y/o redundante • Se relacionan los temas de los materiales revisados con coherencia | | | |
| **Sintaxis, ortografía y estilo** (1) | Incluye los elementos siguientes: • La redacción es coherente • La composición de las oraciones permite una lectura clara • Sin errores gramaticales • Sin errores de ortografía | | | |

## Puntuación total: 10 puntos

### Desglose de puntos:
- Estructura: Sin puntaje (requisito)
- Formato: 0.25 puntos
- Elementos de la wiki: 3.25 puntos
- Contenido: 4 puntos
- Comprensión: 1.5 puntos
- Sintaxis, ortografía y estilo: 1 punto
- **Total: 10 puntos**
